## 🎯 Overview

AskAI is a modern, cross-platform AI assistant that combines beautiful design with powerful functionality. Built with React and React Native, it offers a seamless experience across web and mobile devices.

**Key Highlights:**
- 🤖 **Multiple AI Models** - Choose from GPT-4o, DeepSeek, Gemini, and more
- 🎨 **AI Image Generation** - Create stunning artwork with various art styles
- 📝 **Smart Notes** - Organize your thoughts with tags and search
- 💬 **Persistent Conversations** - Your chats are saved and synced
- 🌓 **Dark/Light Themes** - Beautiful UI that adapts to your preference

## ✨ Key Features

### 🧠 AI Capabilities
- **Advanced AI Integration** - Powered by GPT-4.1 for intelligent responses
- **AI Model Selector** - Choose from multiple AI models dynamically
- **Image Generation** - Create stunning AI-generated artwork
- **Smart Notes** - Organize and manage your thoughts

### 💬 Chat Experience
- **Persistent Memory** - Your conversations are saved and accessible anytime
- **Real-time Interaction** - Instant responses with smooth animations
- **Conversation Management** - Organize and manage multiple chat threads
- **Typing Indicators** - Beautiful animated "✨ AI is thinking..." indicators

### 🎨 Design & UX
- **Dark/Light Themes** - Easy on your eyes, day or night
- **Responsive Design** - Perfect experience on any device
- **Smooth Animations** - Polished UI with Framer Motion (web) and Reanimated (mobile)
- **Modern UI** - Glassmorphism effects and gradient accents

### 📱 Cross-Platform
- **Web App** - React + Vite + TailwindCSS
- **Mobile App** - React Native + Expo (iOS & Android)
- **Shared Backend** - Node.js + Express + MongoDB
